## 📁 Descrição dos Arquivos

### `curso_google_tools.pptx` — Apresentação Geral do Curso
> **Quando usar:** Na abertura do curso, para apresentar o programa ao grupo.

Apresentação institucional com **10 slides** que cobre:

- Capa com identidade visual (Polícia Militar)
- Objetivo geral do curso
- Estrutura dos 5 módulos com duração estimada
- Slide dedicado a cada módulo (conteúdos e atividades)
- Capacidades desenvolvidas
- Slide de encerramento

**Perfil:** Visual limpo, paleta navy/azul com destaque âmbar. Ideal para projeção em sala.

---

### `aulas_google_tools.pptx` — Material de Aula Detalhado
> **Quando usar:** Durante a condução de cada módulo em sala, slide a slide.

Apresentação completa com **23 slides**, dividida em 5 módulos. Cada módulo inclui conteúdo expositivo, exemplos visuais aplicados ao contexto da PM e dicas práticas destacadas.

| Módulo | Slides | Conteúdo |
|--------|--------|----------|
| **1 — Organização Digital** | 3 slides | Google Workspace, estrutura de pastas, compartilhamento seguro |
| **2 — Docs e Planilhas** | 4 slides | Ofícios, edição colaborativa, fórmulas, controle de efetivo |
| **3 — Keep, To Do e Fotos** | 3 slides | Anotações, gestão de tarefas, registro fotográfico operacional |
| **4 — Gestão de Projetos** | 3 slides | Conceitos, quadro Kanban, fluxo de protocolo de documentos |
| **5 — Gemini (IA Google)** | 3 slides | O que é, como criar prompts, aplicações reais e uso ético |

**Destaques visuais:**
- 💡 Caixas de dica em cada slide
- 📌 Exemplos contextualizados (ofícios, escalas, atas, ocorrências)
- Tabelas e quadros Kanban simulados visualmente
- Rodapé com `@karizeviecelli · 2026 · Polícia Militar` em todos os slides

## 📦 Como Usar

### 1. Clonar o repositório
```bash
git clone https://github.com/karizeviecelli/curso-google-pm.git
cd curso-google-pm
```

### 2. Para apresentação em sala
Abra `aulas_google_tools.pptx` no PowerPoint ou Google Slides e apresente módulo a módulo.

### 3. Para impressão das fichas
Abra `fichas_exercicio_google.docx` e imprima em A4, frente e verso.
Recomenda-se imprimir por módulo e distribuir antes de cada bloco.

### 4. Para adaptar o material
Todos os arquivos são editáveis. Para personalizar com o nome da sua unidade:
- No PPTX: edite os rodapés e textos de identificação

## 🎯 Objetivos de Aprendizagem

Ao final do curso, o participante será capaz de:

- [x] Organizar documentos e pastas no Google Drive com estrutura padronizada
- [x] Criar e formatar documentos oficiais no Google Docs com edição colaborativa
- [x] Construir planilhas de controle com fórmulas básicas no Google Sheets
- [x] Usar Google Keep e Google Tasks para gerenciar tarefas e prazos
- [x] Organizar e compartilhar registros fotográficos pelo Google Fotos
- [x] Aplicar conceitos de gestão de projetos com quadro Kanban
- [x] Criar prompts eficientes para o Gemini e usar IA de forma ética
